This article explains the three tabs of PDF Tools & Editor. Use **Edit & Fill** to complete a form, **Merge PDFs** to combine files and **Split PDF** to keep only some pages.

To open the page, select **File Conversion** in the top menu, then **PDF Tools & Editor**.

## Fill and edit a PDF or a form

### Open your file

1. Select the **Edit & Fill** tab.
2. Select **Open a PDF or a photo of a form** and choose your file.
3. Wait while the page shows **Finding the blanks…**.

You can open a PDF, including a locked or scanned one, or an image: JPG, JPEG, PNG, WebP, BMP, TIFF or GIF.

meldra looks for the blanks on each page, such as lines, empty boxes, table cells and tick boxes, and adds boxes you can type into. The toolbar then says how many it found, for example "Found 12 fill-in boxes and 3 tick boxes."

> **Note:** Finding the blanks works on documents of up to 25 pages. If a longer PDF is refused, or no blanks can be found, the PDF still opens and you can type anywhere with **Add text**.

A PDF that needs a password to open cannot be used. Open it, save a copy without the password, and try again.

### Use the tools

Choose a tool in the toolbar. A hint under the toolbar explains each one.

| Tool | What it does |
|---|---|
| **Fill** | Select a highlighted box to type in it. Select a tick box to tick or untick it. |
| **Add text** | Select anywhere on the page to type there. |
| **White-out** | Drag over printed text to cover it. You can then add your own text on top. |
| **Tick** | Select to place a tick. |
| **Cross** | Select to place a cross. |

To change added text:

- Set the text **Size** (6 to 48) and the colour before you type, or select the text and change them.
- Drag the small handle to the left of the text to move it.
- Select an item and then **Delete** to remove it.

You can also drag ticks, crosses and white-out boxes to move them.

### Download the result

1. Check the **File name**. It starts as your original file name with the date and time added. The file is always saved as `.pdf`.
2. To stop anyone changing the filled-in values, tick **Lock the result (no further editing)**.
3. Select **Download PDF**.

To start again with a different document, select **Another file**. Your edits on the current file are cleared.

> **Important:** Your edits exist only on this page until you download. Download before you leave the page or open another file.

## Merge PDFs

1. Select the **Merge PDFs** tab.
2. Select **Add PDFs** and choose two or more PDFs. You can add more files by selecting **Add PDFs** again.
3. To take a file out, select **Remove** next to it.
4. Select **Merge PDFs**.

The files are joined in the order they appear in the list, which is the order you added them. The merged PDF downloads automatically.

You can merge up to 50 PDFs at a time. The merged PDF must stay within your plan's pages per PDF, and each file within your plan's largest file size. See [Plans and limits](/help/plans-and-limits).

## Split a PDF or extract pages

1. Select the **Split PDF** tab.
2. Select **Select PDF to Split** and choose a PDF.
3. Under **Select Pages to Extract/Keep**, every page is selected at first. Select a page to remove it from the selection, or select it again to add it back.
4. Use **Select All** or **Clear** to change all pages at once. The count under the pages shows how many are selected.
5. Select **Extract Selected Pages**.

You get one PDF with the selected pages, in their original order. To use a different PDF, select **Change**.

## Where your files are processed

Page previews are drawn in your browser. Finding the blanks, saving your edits, merging and splitting run on meldra's servers. The page states that files are never stored on meldra's servers.

Opening a file on **Edit & Fill** counts towards your monthly **Conversions and file jobs**. Your plan's file size and page limits apply to all three tabs. See [Plans and limits](/help/plans-and-limits).
