This article shows how to build a dashboard from your answers and how to download your work for a board pack or month-end report.

## Add charts to your dashboard

1. On the **Ask** tab, find the answer you want to keep.
2. Select **Add to dashboard**. The button changes to **On dashboard**.
3. For a report built from one prompt, select **Add all to dashboard** to add every chart.

Open the **Dashboard** tab to see your tiles. Tiles recalculate whenever your data changes.

## Work with tiles

- Change a tile's chart type with the chart buttons on the tile.
- Remove a tile with the cross at its top right.
- Each tile shows the systems it uses.

## Filter the whole dashboard

1. On the **Dashboard** tab, select **Add filter**.
2. Choose a **Column…**, a condition and a **Value…**.
3. Select **Apply**.

The filter applies to every tile whose sources have that column. A tile with a source that lacks the column shows **Not filtered by** and the column name.

> **Tip:** Use a month filter with **from** and **up to** to show one period across every tile.

## Download formats

| What | Button | Formats |
|---|---|---|
| One answer | **Download** under the answer | PDF, PowerPoint, Word, Excel, CSV |
| A report built from one prompt | **Download report** | PDF, PowerPoint, Word, Excel |
| The whole dashboard | **Download dashboard** | PDF, PowerPoint, Word, Excel |

Every file carries the same numbers as the screen:

- Charts are captured as shown. PowerPoint gets native, editable charts where the chart type allows.
- Each chart has its data table (the first 30 rows) and the systems it came from.
- The CSV holds the data of one answer only.
- A dashboard download applies the dashboard filters.

## Download a dashboard

1. Open the **Dashboard** tab.
2. Set any filters you need.
3. Select **Download dashboard**.
4. Choose **PDF**, **PowerPoint**, **Word** or **Excel**.

The file is titled "Meldra dashboard" with today's date.

> **Note:** Your dashboard is kept in this browser. It does not follow you to another device, even when the data is in the Meldra lakehouse.

## Troubleshooting

| Message | What to do |
|---|---|
| Your dashboard is empty | Ask a question, then select **Add to dashboard** on the answer. |
| This tile uses data that has been removed. | The source was deleted. Add the data again, then pin a new answer. |
| The PDF file could not be created. (or another format) | Try again. If it still fails, choose another format. |
| Nothing on the dashboard could be downloaded. | The tiles' data was removed. Add the data again and rebuild the tiles. |
