Step by step
How the application gets built
STEP 01 / DATA INTAKE
InsightSheet as the data layer

Finance, HR, ops, and procurement teams work in InsightSheet-lite — their natural spreadsheet environment. They upload utility bills, headcount exports, supplier sheets, and incident logs. No new tools to learn.

CSV upload Excel paste ERP sync IoT feed
STEP 02 / AI PROCESSING
AI cleans and structures everything

The moment data lands in InsightSheet, an AI pipeline kicks in: column names are auto-mapped, units normalised, emission factors applied, anomalies flagged. Structured rows are produced without manual intervention.

Schema matching Unit conversion Anomaly detection Factor lookup
STEP 03 / VALIDATION
Rules engine enforces quality

Every row passes through framework-aware validation rules. CSRD-required fields are checked for completeness. Values outside expected ranges are flagged for human review before entering the ESG data store.

Null checks Range rules Framework rules Completeness score
STEP 04 / APPROVAL FLOW
Automated sign-off workflows

Validated data is routed through configurable approval chains — ESG Manager → CFO → Board. Each approver sees a diff view. Approved data is locked and audit-logged with full immutability.

Role-based routing Diff view Audit trail E-signature
STEP 05 / ANALYTICS
ML models run on clean data

With verified data in the ESG store, ML pipelines run: net-zero pathway models project trajectories, NLP classifies supplier responses, climate risk models estimate financial exposure, benchmarking pulls peer data.

Net-zero ML NLP classification Climate risk Benchmarking
STEP 06 / REPORTING
One-click multi-framework reports

The reporting engine maps each verified data point to its framework disclosures simultaneously. LLM drafts narrative sections grounded in actual data. Human-approved final report exports as PDF and iXBRL in one click.

GRI · CSRD · TCFD LLM narratives PDF export iXBRL / XBRL
InsightSheet-lite specifics
What meldra.ai provides natively
InsightSheet-lite is described as "Data Made Simple" — a lightweight AI-powered data intelligence layer. Here is exactly how each of its core capabilities maps to the ESG application.
InsightSheet capability
AI-powered spreadsheet ingestion

Users paste or upload messy tabular data. InsightSheet AI understands column intent (even with inconsistent headers), fills gaps, and produces clean rows.

ESG use: Energy bills → EnergyRecord · HR exports → WorkforceSnapshot · Incident logs → SafetyIncident
InsightSheet capability
Formula & calculation engine

AI generates formulas on command. Users can say "calculate tCO₂e from kWh using DEFRA 2024 factors" and InsightSheet writes and applies the formula automatically.

ESG use: Emission factor × activity data = tCO₂e · TRIR computation · Pay gap calculation
InsightSheet capability
Data validation & anomaly alerts

InsightSheet highlights cells with unexpected values, type mismatches, or outliers — surfacing problems before data is accepted as clean.

ESG use: Flags 300% month-on-month energy spikes · Missing mandatory CSRD fields highlighted in red
InsightSheet capability
API / webhook push

Structured, validated output rows can be pushed via REST API or webhook to any downstream system — the bridge into the ESG data store.

ESG use: POST /api/esg/ingest on InsightSheet save → triggers ESG validation pipeline

AI & machine learning
9 ways AI powers the ESG platform
Every AI and ML capability — what it does, how it works technically, and exactly where InsightSheet provides the data foundation.
01 · DETECTION

Anomaly detection

Statistical models monitor every incoming data point against rolling 12-month baselines. Outliers trigger alerts before data is approved — preventing report errors at source.

HOW IT WORKS
InsightSheet flags values where Z-score > 2.5 on save
IQR outlier model runs on rolling 12-month window per entity
Validation rule engine blocks or warns based on severity config
Z-scoreIQRscikit-learn
02 · PREDICTION

Net-zero pathway modelling

ML regression and Monte Carlo simulation project emission trajectories under configurable intervention scenarios — showing which levers close the gap to SBTi targets.

HOW IT WORKS
Historical tCO₂e from ESG store feeds regression model
User adjusts levers (renewables %, efficiency gains) via sliders
Monte Carlo runs 10k simulations, outputs confidence bands
RegressionMonte CarloProphet
03 · GENERATION

LLM narrative drafting

Self-hosted Mistral/Llama APIs generate first-draft disclosure narratives grounded in actual verified ESG data via RAG. Human review and approval is always required before publication.

HOW IT WORKS
Verified ESG metrics retrieved from store and injected as context
Framework disclosure requirements passed as system prompt
Draft stored with model version; human edits approved_text field
Self-hosted LLMRAGHuman-in-loop
04 · CLASSIFICATION

Supplier NLP risk scoring

Free-text supplier questionnaire responses are classified by NLP models into structured risk categories. Spend × risk score auto-assigns tier without manual review.

HOW IT WORKS
InsightSheet ingests supplier response CSVs, sends text fields via API
Fine-tuned BERT classifier maps responses to risk categories
Score = weighted sum of category scores × spend weight
BERT NLPText classificationHuggingFace
05 · EXTRACTION

Document intelligence (OCR + LLM)

Utility invoices, audit certificates, and policy documents uploaded to InsightSheet are parsed by OCR and LLM pipelines, extracting structured ESG fields automatically.

HOW IT WORKS
PDF/image uploaded → Tesseract OCR extracts raw text
LLM prompt extracts structured fields: kWh, date, site, cost
Confidence score attached; low-confidence fields flagged for review
TesseractLLM extractConfidence scoring
06 · RECOMMENDATION

Materiality assessment AI

Clustering and sentiment NLP analyse stakeholder survey responses and peer disclosures to pre-score your double materiality matrix before the working group meets.

HOW IT WORKS
Survey responses collected in InsightSheet and sent to NLP pipeline
K-means clustering groups topics by stakeholder salience
Outputs pre-filled impact × financial score matrix for review
K-meansSentiment NLPPeer benchmarks
07 · FORECASTING

Climate risk quantification

Geospatial ML maps your asset locations against IPCC climate scenario data to estimate financial exposure from flood, heat stress, and water scarcity under 1.5°C and 4°C pathways.

HOW IT WORKS
Asset lat/lng from property data cross-referenced with CMIP6 climate data
Hazard intensity × asset value × vulnerability score = financial impact
Outputs TCFD-structured physical risk table per scenario
GIS/spatial MLCMIP6 dataTCFD output
08 · AUTOMATION

Smart schema mapping

Few-shot ML learns field mappings between source systems (SAP cost centres, Oracle GL codes) and ESG data model fields — reducing ERP integration setup from weeks to hours.

HOW IT WORKS
InsightSheet analyses incoming column names and sample values
Cosine similarity against known ESG field embeddings suggests mapping
User confirms or overrides; confirmation improves future suggestions
EmbeddingsCosine similarityFew-shot
09 · INSIGHT

Peer benchmarking intelligence

NLP pipelines continuously extract ESG metrics from public CDP submissions, CSRD filings, and Bloomberg data — building live sector benchmarks you can compare against in real time.

HOW IT WORKS
Nightly job fetches public CDP disclosures and CSRD XBRL filings
NLP entity extraction pulls tCO₂e, intensity, diversity metrics per company
Sector percentile ranks computed and served to benchmark dashboard
NLP extractionXBRL parsingRanking models
