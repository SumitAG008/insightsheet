Unified Reporting test pack

Four exports from four systems. On their own, none of them can answer the questions below; together they can. That is what unified reporting means: Meldra links the systems and answers across them.

employees.csvexpenses.csvbudget.xlsxopportunities.xlsx

Test script

  1. Open Unified Reporting → Data sources. Click Remove all data if anything is there.
  2. Click Choose files and select all four files at once (Ctrl or ⌘ + click), or drop them together.
  3. Check you see 4 sources: employees (24 rows), expenses (90), budget (30), opportunities (40).
  4. Under Links between sources, click Link for:
    expenses.employee_id → employees.employee_id
    opportunities.owner_employee_id → employees.employee_id
  5. Under Shared dimensions you should see department and month.
  6. Go to Ask and type each question below exactly. Compare the answer (switch to Table, or CSV) with the expected numbers.
  7. Switch the composer to Build a report and type Department cost and pipeline report: you get several charts drawing on the four systems. Click Add all to dashboard, then Excel.
